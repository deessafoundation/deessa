# Admin Guide: Uploading Testimonial Images

## Quick Start

### Step 1: Access Homepage Manager
1. Login to admin panel
2. Navigate to **Homepage Manager**
3. Scroll to **Testimonials** section

### Step 2: Choose Upload Method

#### Option A: Use Image URL
1. Click the **URL** tab
2. Paste the image URL
3. Preview appears automatically

#### Option B: Upload from Computer
1. Click the **Upload** tab
2. Click **Choose File** button
3. Select an image (JPG, PNG, or WebP)
4. Wait for upload to complete
5. Preview appears automatically

### Step 3: Save Changes
1. Review the preview
2. Click **Save Changes** button
3. Wait for success notification

## Workflow Example

### Adding a New Testimonial with Image

1. **Prepare the image**
   - Crop to 400x400 pixels
   - Compress to under 500KB
   - Save as JPG or WebP

2. **Add testimonial in CMS**
   - Click "Add New Testimonial"
   - Fill in name, role, location
   - Write the testimonial quote

3. **Upload the image**
   - Click "Upload" tab
   - Select prepared image
   - Wait for upload (usually 2-5 seconds)
   - Verify preview looks good

4. **Review and save**
   - Check all fields are correct
   - Review preview at bottom
   - Click "Save Changes"
   - Wait for success message

5. **Verify on website**
   - Visit homepage
   - Scroll to testimonials section
   - Confirm image displays correctly
   - Test on mobile device

## Mobile Upload

### On Mobile Devices
1. Tap "Upload" tab
2. Tap "Choose File"
3. Select from:
   - Camera (take new photo)
   - Photo Library (existing photo)
   - Files (from cloud storage)
4. Wait for upload
5. Review preview
6. Tap "Save Changes"

### Mobile Tips
- Use camera for instant photos
- Ensure good lighting
- Hold phone steady
- Use portrait mode if available

## Frequently Asked Questions

### Can I upload multiple images at once?
No, currently one image per testimonial. Upload each separately.

### Can I reuse an uploaded image?
Yes, copy the URL from one testimonial and paste it in another.

### What happens to old images when I upload new ones?
Old images remain in storage but are replaced in the testimonial.

### Can I delete uploaded images?
Yes, click the X button next to the preview to remove.

### Do images work on mobile?
Yes, images are responsive and work on all devices.

### Can I edit images after upload?
No, prepare images before uploading. Re-upload if changes needed.

### Are images backed up?
Yes, all images are stored in Supabase Storage with redundancy.

### Can I use images from other websites?
Only if you have permission. Prefer original photos.
