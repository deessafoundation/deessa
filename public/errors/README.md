# Error-page artwork

All artwork is local WebP, generated with ImageGen and encoded with Sharp. The scenes are illustrative, not documentary photographs of foundation participants. A person's appearance does not establish an autism diagnosis.

| State | Main artwork | Scene |
| --- | --- | --- |

| 500 | neurodiversity-500.webp | supported-bridge.webp |
| Connection | connection-infinity.webp | girl-connection-error.webp |
| 403 preview | permission-403.webp | permission-door.webp |
| Unexpected error | unexpected-oops.webp | supported-bridge.webp |
| Registration closed/ended | registration-calendar.webp | next-gathering.webp |

Numeral/symbol artwork is transparent, 1200 x 540. Scenes are 1000 x 1250 except the connection portrait (768 x 768). The 404 follows the supplied puzzle/hand reference. Later artwork uses infinity, sensory textures, supported play, a welcoming doorway, and a prepared workshop. Ocean blue is the primary color; muted red distinguishes server failure.

Headings, descriptions and recovery actions are HTML. Images are decorative and do not carry essential instructions. Crops, cream backing shapes and motion are implemented in the shared renderer and CSS. Reduced-motion, sensory-friendly, contrast and print modes are supported.

Rejected child portraits, repair/cable scenes and superseded numeral drafts were removed in the October 8 audit after checking references. Original generation outputs outside this repository were left intact.

Preview collection: /demo/errors. It is marked no-index. The 403 preview does not enforce authorization; the connection preview does not provide offline caching.
