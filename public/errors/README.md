# Error-page artwork

The current artwork uses newly generated imagined scenes based on the facial references supplied by the user from /our-story: public/twin-solo-2.jpg and public/twins-curious.jpg. Original story photos remain unchanged. Generated images are illustrative reconstructions, not documentary photographs or evidence of a diagnosis.

- girl-not-found.webp: girl looking between a tablet and learning folder with an open palm, mildly puzzled.
- girl-server-error.webp: girl trying an unresponsive tablet, disconnected charging cable nearby.
- girl-connection-error.webp: girl examining a loose network cable beside a router and tablet.

Built-in ImageGen, 2026-10-05. Shared prompt direction: preserve recognizable facial proportions, dark eyes, straight black fringe and shoulder-length hair from the references; new respectful staged scene, ocean-blue cotton clothing, white/pale-blue inclusive learning room, natural daylight, convincing hands and props, no exaggerated distress, medical stereotypes, logos, text or readable UI. Original printed cartoon clothing is not reproduced.

The installed Sharp dependency encodes square 768px WebP at quality 86. Originals remain in Codex generated_images. No remote image service is required. Earlier child-*.webp drafts are not used by the pages.

Typography matches the public site: Marissa Font headings and Comic Neue body copy, with shared ocean/deep-ocean brand tokens and neutral body text. Artwork is decorative; headings and recovery actions communicate each state independently. Motion can be paused and respects reduced-motion and sensory-friendly modes.

/demo/errors previews eight states, contrast, 200% text and simulated retry outcomes. These controls do not change real authorization or connectivity. Initial offline navigation still requires separate caching.
