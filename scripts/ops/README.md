# Ops Scripts

Day-to-day operational tooling (env, secrets, route hygiene).

| Script | Purpose |
|--------|---------|
| `check-env-vars.js` | Verify required env vars are present |
| `validate-payment-config.ts` | Validate payment provider configuration |
| `generate-secrets.ps1` / `.sh` | Generate secrets (e.g. AUTH_SECRET) |
| `test-credentials.ps1` / `.sh` | Test stored credentials |
| `scan-all-routes.ps1` | Scan app routes for issues |
